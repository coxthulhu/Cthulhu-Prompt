There seems to be a bug when we have a category selected when the application closes. When we select a category in the prompt tree either by navigating in the sidebar or by scrolling in the prompt folder screen, then close the application and reopen it, we're brought back to the top of the prompt folder screen. But if we do this with a prompt it correctly brings us back to the prompt. Why is this?
