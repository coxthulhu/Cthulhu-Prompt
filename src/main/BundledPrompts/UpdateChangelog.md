---
title: "Update the Changelog"
---
Read the repository's changelog and release tags to identify the latest release. Review the changes since that release and identify changes a user would notice.

Compare those changes with the existing changelog. Add any missing entries using its existing headings, ordering, and writing style. Group related changes and avoid duplicating entries from earlier runs.

If every user-visible change is already covered, leave the file as it is and report that the changelog is current.
